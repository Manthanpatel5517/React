# Practical Management Dashboard

Modern React + Vite student practical management dashboard.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Features
- Responsive sidebar
- Mobile navigation
- Dashboard stats
- Search
- Status filter
- Date sorting
- Practical table
- Submission status
- Detail modal
- Progress indicator
- Reusable React components
- Lucide icons
