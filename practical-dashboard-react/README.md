# PracticalHub – React Practical Dashboard

A modern, responsive React/Vite practical management dashboard inspired by the supplied reference image.

## Features
- Responsive sidebar navigation
- Mobile hamburger menu
- Practical statistics cards
- Search practicals
- Completed/Pending filter
- Practical table matching the reference concept
- Submission links
- Feedback/marks display
- Lucide React icons
- Modern responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Main files
- `src/App.jsx` – UI and practical data
- `src/App.css` – complete responsive styling
- `src/main.jsx` – React entry point
